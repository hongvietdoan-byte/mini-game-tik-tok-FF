4. Logic code phải bảo toàn (contract)

Backend là nguồn sự thật: state machine, timer, scoring, random seed, danh sách câu, leaderboards,
voice transition. Overlay chỉ render snapshot/delta; không tự tính điểm, không lộ correctAnswer trước
reveal.

Event contract tối thiểu:

   type GamePhase = 'IDLE'|'LOBBY'|'PREPARE'|'READING'|'ACCEPTING'|'REVEAL'|'LEADERBOARD'|'ROUND_FINISHED'|'INTERMISSION
   '|'PAUSED'|'CONNECTION_INTERRUPTED'|'ERROR';
   interface LiveComment { source:'TIKTOK'|'MOCK'; eventId?:string; userId:string; displayName:string; text:string; receivedAt:numb
   er; }
   interface AnswerRecord { roundId:string; questionInstanceId:string; playerId:string; answer:'A'|'B'|'C'|'D'; receivedAt:number; acce
   pted:boolean; rejectionReason?:string; }
   interface PlayerAppearance { roundId:string; playerId:string; characterId:string; seatId?:string; }
   interface VictoryEntry { rank:number; playerId:string; displayName:string; score:number; characterId:string; }

Tính đúng đắn: UNIQUE(roundId, questionInstanceId, playerId) cho đáp án đã nhận;
transaction/idempotency khi chấm; stable identity không dựa nickname; không tính lại sau reconnect;
lưu snapshot câu để việc sửa ngân hàng không thay đổi lịch sử; pause lưu remaining time; crash recovery
không tự bật timer; đồng hạng xử lý nhất quán.

35 ghế: 7×5, ghế chỉ là visual. Khi có >35 player, dùng lịch luân chuyển giữa các câu, giữ một số vị trí ưu
tiên cho người mới hoặc người vừa trả lời (cấu hình, không ưu tiên điểm). Không render 2.000 avatar
cùng lúc. Không thay nhân vật người chơi chỉ để tránh trùng Top 3.

MC Voice: dùng một API TTS người dùng cung cấp. Settings có endpoint/voice/model/key theo schema
thật của API; key backend only; test voice; cache theo nội dung + voice config; pre-generate audio câu
hỏi; queue không chồng tiếng; skip/stop/pause hủy đúng; chỉ một audio output OBS thu được; nếu API lỗi
→ cache → silent fallback. Không tự giả định format API. Với lời thoại dynamic như tên Top 3, sanitize và
giới hạn nội dung. Giọng đọc phải tuân thủ quyền sử dụng.

PNG Sequence: idle, talking, victory là khả năng mở rộng; khi chưa có frame thật phải báo thiếu asset,
render ảnh tĩnh, không tạo giả animation hoàn chỉnh. Preload/cache texture, FPS cấu hình, fallback và
reduced motion.
